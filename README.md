# ED25519 key hopping
ED25519 key offline, no contact hopping concept.

The concept has so far only been validated by Claude and MathGPT, two AIs.

The idea is that by multiplying the signature's private key by a random but forecastable scalar, one obtains a brand new public key, and since the scalar can be known publicly, the accompanying private key can easily be re-calculated offline.

Essentially this creates a unidirectional signed data transmission with pre-programmed key hopping, where new keypairs do not have to be agreed upon again and again.

It is a possible component of the digital swamp anti-personnal smart mine system.
